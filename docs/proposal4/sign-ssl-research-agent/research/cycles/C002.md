## Critique

- Chamfer is a known fine-grained video-similarity readout (ViSiL, TCA, DnS); the finding is the size of the gap for a sign encoder evaluated with averaging, not the readout itself.
- Rerank depth is 20 classes by wmean; R@1 can only improve when the true class is in that set (no upper-bound issue at R@1 here, but R@20 ceiling exists).
- Gain is not movement-specific (no-movement signs gain similarly) → the earlier "movement" framing (GAP2) is weakened; the better description is that averaging dilutes the discriminative windows of a sign with rest/transition/hold windows and with signer-specific segments.
- Chamfer costs O(Lq·Lg) per pair and needs window sets in the index (≈ 36× storage of a single vector).

## Decision (D005)

Pivot the method search from encoder-level temporal objectives (two nulls) to the measured bottleneck: **label-free learning of a single-vector sign embedding that keeps set-matching information** (H004), with chamfer as the teacher/upper reference and bins2 as the training-free floor. Generality checks (second dataset, second encoder) are required before any paper claim.
