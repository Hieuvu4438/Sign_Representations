7. **Signer nuisance:** same-signer distractors lower WLASL R@1 by 2.4 points (0.328 → 0.304 when present). A label-free method that removes signer/appearance components without hurting sign content is a candidate method direction (GAP4), measurable with this distractor test.
3. **What does chamfer exploit?** (partly answered, exploratory val, 3000 queries, `scripts/explore_chamfer_variants.py`): query→gallery one-directional 0.687 ≥ symmetric 0.683 > partial (best 50% query windows) 0.636 > gallery→query 0.621 > wmean 0.589 R@1. → The gain comes from **every query window finding a counterpart anywhere in the exemplar** (phase coverage without alignment), not from ignoring non-matching parts; position penalties add nothing. Open: can an encoder objective make centroids preserve this coverage property?
4. **Method direction implied by the evidence (not yet tested):** pretraining objectives whose *clip-level* target is partial/set matching between different realisations of the same sign — label-free positives are unavailable in isolated-sign corpora, so this needs either continuous-signing corpora with repeated signs (e.g. sign spotting pseudo-pairs) or weak supervision; must be compared against "original checkpoint + ordered readout", the baseline set by C012.
