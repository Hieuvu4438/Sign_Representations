# H012b — Distillation with cross-pseudo-signer candidates (POST-HOC, exploratory)

Opened 2026-10-07 after seeing H012's P2 result (+5.6 cross-signer precision). Because it was conceived after that number, everything here is exploratory until a new locked protocol confirms it on data not used for selection.

| Trường | Giá trị |
| --- | --- |
| Setting | label-free (no gloss, no signer metadata): pseudo-signer clusters K=20 from rest-segment descriptors (`runtime/explore/restpose_clusters_train.npy`, chosen by silhouette) |
| Reference setting (declared separately) | gloss-free but **signer-metadata-supervised**: true signer IDs replace clusters (`oracle_signer_ids_train.npy`). Reported as an upper bound / separate setting, never as label-free |
| Base | H008 D2 exactly (`--arm H4 --batch 64 --steps 12000 --tau 0.03 --teacher q2g --seed 0`), so the only change is the candidate/teacher treatment of same-cluster pairs |

## Arms (declared before any H012b run)

| Arm | Change vs D2 | Supervision |
| --- | --- | --- |
| X1 exclude | the 64 wmean candidates are drawn only from other pseudo-signer clusters | none |
| X2 penalty | same candidates as D2; teacher similarity − 0.1 for same-cluster candidates (teacher debiasing; same-cluster clips remain student negatives) | none |
| XO oracle-exclude | as X1 with true signer IDs | signer metadata |

## Predictions and go rule

- P1: max(X1, X2) − D2 ≥ +1.5 val R@1, signer-cluster bootstrap CI > 0 (6 val signers; disclosed as few clusters).
- P2: XO ≥ max(X1, X2) (better nuisance estimate → better student); the gap measures headroom for improving the pseudo-signer estimate.
- Go: P1 met → write EX14 (locked) covering the best label-free arm (selected on val among X1/X2), H011 if it passed its own rule, M2D2 training-free baseline, on ASL Citizen test + WLASL + MS-ASL (clusters recomputed on each dataset's own unlabelled train set with the same K-selection rule). Not met → record; pseudo-signer mining stops at diagnostic level and is reported as a measurement (H012 table).

## Transfer limitation measured before any H012b result (2026-10-07)

`scripts/pseudo_signers.py` on the other datasets' unlabelled train windows (`runtime/explore/restpose_clusters_*.json`):

| Train set | clips | no rest segment (fallback to first+last window) | K selected |
| --- | --- | --- | --- |
| ASL Citizen | 40,154 | 5.5% | 20 |
| WLASL2000 | 14,296 | **59.0%** | 20 |
| MS-ASL | 12,711 | **66.8%** | 80 |

FACT: WLASL/MS-ASL clips are mostly trimmed to the sign, so the rest-segment nuisance estimate is unavailable for most clips (fallback windows contain sign content). INFERENCE: H012b is expected to transfer weakly to these datasets; any EX14 secondary result there tests a degraded variant and must be reported as such. Applicability condition of the method: dictionary-style recordings with rest pose before/after the sign (ASL Citizen-like self-recordings).

## Dev result (val; `runtime/explore/H012b_vs_D2_val.json`)

| Arm | val R@1 | − D2 (0.6752) |
| --- | --- | --- |
| X1 exclude same pseudo-signer cluster | 0.6788 | +0.36 [0.00, +0.65], 4/6 |
| X2 teacher penalty | 0.6777 | +0.25 [−0.80, +1.42], 3/6 |
| XO oracle (signer metadata; finished after the decision) | 0.6838 | +0.86 [+0.01, +2.24], 5/6 |

**P1 NOT MET** → H12b is not an EX14 arm; the H11+12b combination is not run (its inclusion was conditional on H12b). The +5.6 point gain in top-1 mining precision (H012) did not transfer to the distilled student (+0.36). INFERENCE (to test): the student is trained on the full teacher distribution over 72 candidates, not on top-1 positives, so changing which 64 candidates are listed changes the target little; and the student already sits 3.5 points below its own teacher (T4 0.727 vs H11 0.692), so the limiting factor is the set→vector distillation capacity/objective rather than the candidate composition.

XO result (reference, separate supervision setting): even exact signer exclusion gives < +1 R@1 over D2 although it raises top-1 cross-signer mining precision by +19.4 points (H012). This strengthens the inference that candidate composition is not the bottleneck of the distilled student. P2 (XO ≥ max(X1, X2)) holds descriptively (0.6838 > 0.6788).
