# H005 — Label-free nuisance reduction of frozen sign embeddings by gallery PCA-whitening

## Identity

| Trường | Giá trị |
| --- | --- |
| Status | REFUTED (EX07-v1, MS-ASL test: R1W − R1 = −2.39 R@1 [−3.82,−0.95]); window-level whitening + chamfer +2.42 (secondary, descriptive) |
| Version / date | v1, 2026-10-06 |
| Gap | GAP4 (signer/appearance nuisance): same-signer distractors lower WLASL R@1 by 2.4 points (exploratory) |
| Supervision | none beyond the gallery itself: whitening statistics are fitted on unlabelled train-gallery vectors (no gloss, no signer IDs) |
| Scope | frozen dictionary retrieval with SignRep; post-hoc transform (not an encoder change) |

## Argument

- Observation: dominant variance directions of frozen SignRep clip vectors are shared across many signs (signer, background, rest posture); equalising variance (whitening) lets low-variance, sign-discriminative directions count. Exploratory val evidence: wmean 0.5949 → 0.6384 (+4.35), bins2 0.6491 → 0.6748 (+2.57); window-level whitening + chamfer 0.675 → 0.703 (3,000-query subset). Removing only the top few PCs ("all-but-the-top") or centring does **not** help (−0.1 … −1.7), so the gain is not from deleting one nuisance axis.
- Alternative explanation: generic retrieval effect of whitening (known in image retrieval: PCA-whitening of global descriptors) unrelated to signer nuisance. This test cannot separate the two; a signer-specific diagnostic is needed (e.g. same-signer distractor test before/after whitening).
- Refutation (EX07): R1W − R1 ≤ 0 on MS-ASL test.
- Novelty: low as a technique (PCA-whitening is standard in instance retrieval); value would be as part of a strong label-free evaluation baseline for sign encoders.

## Mechanism diagnostic (exploratory, WLASL val, `scripts/explore_whiten_signer.py`, run after EX07 was locked)

| Readout | official gallery (signers shared) | signer-disjoint gallery | same-signer penalty |
| --- | --- | --- | --- |
| wmean | 0.3043 | 0.3304 | +2.60 |
| wmean + whiten | 0.2844 | 0.3288 | +4.44 |
| bins2 | 0.3186 | 0.3449 | +2.63 |
| bins2 + whiten | 0.3036 | 0.3515 | +4.80 |

Whitening **increases** the same-signer distractor penalty and hurts when signers are shared → the "nuisance reduction" mechanism is contradicted; whatever whitening does on ASL Citizen val is not signer-nuisance removal (INFERENCE: it up-weights fine-grained directions that include signer-specific detail; helpful only when gallery and query signers differ). Prediction for EX07 therefore uncertain; protocol unchanged.

## Decision rule

See EX07-v1. If supported, the recommended frozen baseline becomes "SignRep + bins2 + gallery whitening" (single vector) and "window whitening + chamfer" (set); any new SSL objective must beat these.
