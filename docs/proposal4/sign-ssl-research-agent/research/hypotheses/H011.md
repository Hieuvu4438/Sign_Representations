## Prior-art update (2026-10-07, search_log_F, written before H011 dev result)

- SemanticMoments (arXiv 2602.09146, ABSTRACT_READ) already shows training-free temporal statistics of pretrained features reduce appearance bias for motion retrieval (generic video); CLIP2Video's Temporal Difference Block (2106.11097) learns over adjacent-frame embedding differences. The *mechanism* "temporal differences cancel appearance" is therefore not novel.
- Consequence for claims: any H011/EX14 claim must include a SemanticMoments-style moment readout as a control (`scripts/explore_moments.py`, val only, exploratory). If moments ≥ T4 on val, the temporal-difference *chamfer* teacher has no specific advantage and the paper should cite/compare rather than present it as new.

## Moments control result (val, exploratory; `runtime/explore/moments_control.json`)

| Readout (3,000 val queries) | type | R@1 |
| --- | --- | --- |
| M1 temporal mean | 1 vector, 768-d | 0.5813 |
| M2 mean+std | 1 vector, 1536-d | 0.6300 |
| M3 mean+std+3rd moment (SemanticMoments-style) | 1 vector, 2304-d | 0.6377 |
| M2D2 moments of windows + moments of temporal differences | 1 vector, 3072-d | **0.6663** |
| T4 chamfer(windows)+chamfer(diffs), rerank20 | set | 0.7257 |
| T4 + M2D2, rerank20 | set | 0.7293 |

- Moments do **not** reach the set readout T4 (−5.9 for M2D2 rerank) → set matching on temporal differences carries information beyond temporal statistics; the "moments ≥ T4" kill condition is not triggered.
- But a training-free single vector (M2D2, 0.666 on this subset) is close to the *trained* H008 student (0.6752 on full val; different query sets, so not a paired comparison). This is a necessary baseline for any H008/H011 claim: the student must be compared to M2D2 at equal or reported dimension, paired, on the same queries. (INFERENCE: much of H008's gain over R0/R1 may be reachable by second-order statistics; to be tested.)

### Full-val paired check (`runtime/explore/moments_full_val.json`)

H008 student 0.6752 vs training-free M2D2 0.6529 (+2.23 [+1.32, +3.53], 5/6 val signers) and vs dimension-matched M2D2-PCA1024 0.6475 (+2.77 [+1.55, +4.14]). The distilled student beats the strongest training-free single vector found so far, but by ~2–3 points, not the ~8 points it shows over R0. **The M2D2 moment vector is a required baseline in any H008/H011 paper table** (to be added under a new locked protocol, since test splits are already seen).
