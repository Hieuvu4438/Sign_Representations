## Diagnosis (INFERENCE)

No anchor tied the student's embedding to the original space (unlike XWP, whose anchor kept it within ±0.5 R@1); the linear heads absorbed the targets while the retrieval embedding drifted. A version with an anchor would test the idea more fairly but is a new hypothesis (would need a fresh protocol); given that every anchored continuation so far moved retrieval by < 1 point, its expected value is low.
