## Strongest rejection case

The mechanism is generic (predict a frozen teacher's latent of another temporal region) and the closest work already shows its limits: SALT gets strong representations from frozen-teacher **same-clip** masked latent prediction; FRAME's future-feature anticipation helps dense correspondence but not clip classification (HMDB +0.7, UCF −0.4); P403 attributes arrow-of-time sensitivity to latent prediction **without** needing future-only targets. So a +0.5 R@1 gain over the untouched checkpoint is most plausibly in-domain continuation/self-distillation, which C0/A0 will expose. Even if M0 > C0, the effect size so far (+0.5 R@1) is below the pilot δ (+1.0 vs C0), and novelty would rest on the sign-domain diagnostics rather than the objective.

## Decision

- **Decision:** CONTINUE the pilot to completion (no change to protocol); prepare to REJECT H002 as a primary contribution unless M0 − C0 ≥ +1.0 R@1 with the movement-cohort pattern.
- Rationale: prior-art pass shows the objective itself is not novel; only a large, mechanism-specific effect would justify it.
- What would reverse the decision: M0 − C0 ≥ +1.0 R@1, ≥ 5/6 signers, gain concentrated on non-repeated path movements, and larger reversal sensitivity than C0.
- Next informative action: finish C0/A0; then the CIP-Sign gate test requested by the user (proposal5), which tests a different mechanism (cross-articulator predictive increments) at low cost.
