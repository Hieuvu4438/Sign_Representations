## Critical analysis

- INFERENCE: random per-gloss 4:1:1 split with 119 signers → test signers largely seen in training; WLASL accuracies are signer-dependent and not comparable to ASL Citizen / MS-ASL signer-independent numbers.
- Label noise / gloss inconsistency documented by P308 (same sign different glosses; same gloss different signs; questionable "dialect variants"; identical videos with distinct IDs and different glosses).
- YouTube provenance → overlap risk with YouTube-based SSL corpora (SignRep explicitly removed WLASL videos from YT-SL-25 per SignRep paper; see P314/anchor). Video availability decays.
- License C-UDA — check before redistribution.

## Liên hệ project

- Use WLASL2000 only as secondary, report P-I and P-C, and state signer-dependence; consider a signer-disjoint re-split using provided signer IDs as a supplemental diagnostic (signer IDs are FaceNet-derived — re-identification concerns: use only provided IDs, do not re-derive from faces).
- Cheap check: count train/test signer overlap in `WLASL_v0.3.json` (signer_id field) to quantify; record as FACT once computed.
