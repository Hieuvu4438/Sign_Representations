## Critical analysis

- Strengths: explicit motion-residual targets (velocity-like) in masked modelling; confidence threshold justified empirically; noise robustness table.
- Author-stated future work (§V): general pose estimators lack precision for interacting hands; fixed motion interval limits modelling various motion → suggests multi-scale motion.
- INFERENCE: 32-frame input; global semantic alignment via average pooling (order-invariant readout); in-domain pretraining.

## Liên hệ project

- H-seed-A: closest pose-modality prior art for "predict motion targets at masked positions". RGB-encoder + motion-prior targets (SignRep-style) would need to differ by modality/target horizon/eval.
- H-seed-B: hard threshold 0.4 is a baseline to beat.
