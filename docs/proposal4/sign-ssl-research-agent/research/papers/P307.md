## Critical analysis

- Label noise risk: text/OCR-derived labels, non-native annotators; dialect variants within a class ("5 common signs for the word Computer", §3.4) → class = English word, not sign.
- INFERENCE: signer identification by face clustering may merge/split signers; signer independence is approximate.
- Contamination: any YouTube-scale SSL pretraining (YouTube-ASL; YouTube-SL-25 used by SignRep) may contain MS-ASL test videos. For SignRep the MS-ASL/YT-SL-25 overlap is UNKNOWN unless the anchor paper documents a check (SignRep documents a WLASL check only, per HTML summary).
- Metric differences: per-class (official) vs per-instance (many SSL papers) — must state which.
