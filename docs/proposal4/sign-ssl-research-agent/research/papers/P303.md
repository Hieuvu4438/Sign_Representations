## Mechanism

- Auxiliary phoneme classification shares the encoder; authors argue handshape/minor location are discriminative sub-lexical units and that ~70% of ASL-LEX signs are uniquely identified by phonemes (§2).
- Utility U(P) = fraction of sign pairs disambiguated by a phoneme subset (lookup-table P(S|P)); greedy/argmax subset P*(n) (§3.3).

## Critical analysis

- Strength: clean ablation with seeds and significance; first to show a linear-probe-on-frozen-encoder vs trained phoneme head comparison.
- Author limitations: WLASL label noise propagates to phoneme labels; one language; no I3D (§6).
- INFERENCE: joining by English gloss string is error-prone (WLASL glosses are not 1-1 with signs, P308), unlike ASL Citizen's code-based join (P302).
- INFERENCE: phoneme probes are evaluated on test videos of the same glosses seen in training (signer-dependent WLASL split) → probe accuracy partly measures gloss identification; no gloss-disjoint phoneme evaluation.
- Confound: auxiliary-head gain could be regularization/multi-task capacity rather than phonology per se; no control with random/shuffled phoneme labels.

## Liên hệ project

- Supports using ASL-LEX features as (supervised) diagnostics; a frozen-representation linear probe per phoneme type is an established protocol (Fig. 3) but needs gloss-disjoint split and majority baseline.
- Using phoneme labels as an auxiliary loss would be extra supervision — a separate setting per project rules.
- Cheap control to add: shuffled-phoneme-label probe (assign each gloss a random feature vector with matched marginals) to separate "gloss identity" from "phonological content".
