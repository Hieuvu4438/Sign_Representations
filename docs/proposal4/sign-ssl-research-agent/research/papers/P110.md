## Critical analysis

- Strengths: reports a ladder of regimes (zero-shot → kNN → linear → FT) on ASL Citizen — the clearest example of how much frozen pose-text features lose relative to FT.
- Author limitations: data scale; Spreadthesign not releasable; ASL-only evaluation; compute budget (1 A100, <3 days); short context; "static embedding approach" with suggested ablation on video length (§Limitations).
- Downstream citations misuse: SHuBERT P101 cites SignCLIP 0.60 (FT+linear); SSL-SLR P103 cites 46.00 (FT); both labelled just "SignCLIP" (INFERENCE from cross-reading).
- Temporal: average pooling of transformer tokens; no order analysis; temporal speed augmentation (E7.2) improves zero-shot.
- Nuisance: test-time pose flipping for left-handers (E8); pose normalisation; no signer analysis.

## Liên hệ project

- Use as text-supervised frozen-feature reference only. Shows that a 10-shot kNN frozen protocol on ASL Citizen is very hard for pose-text features (R@1 0.05) vs SignRep full-train-gallery retrieval (49.95 Rec@1, SignRep Table 4) — galleries differ, do not rank.
