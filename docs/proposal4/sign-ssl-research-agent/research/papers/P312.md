## Critical analysis

- Strength: controls lexical memorization (sign-held-out retraining) and signer (cross-signer pairs) — the two confounds that plague token-level phonology probes (P302).
- INFERENCE: "win rate vs random-init" depends on the random-init baseline's own sensitivity (random ST-GCN on pose already encodes handshape geometry); a frozen SSL encoder would need the same random-init control with the same architecture.
- Small location set (31 pairs) → wide uncertainty.

## Liên hệ project

- Closest prior protocol for "what does a frozen representation encode (handshape vs location vs movement)". Explicitly leaves SSL models untested → opportunity to evaluate SignRep and the project's encoder on the released pairs (subject to their license), plus an expanded ASL-LEX-coded pair set (P302 LOCAL_AUDIT supply).
- Since SSL pretraining here never uses ASL Citizen labels, gloss-held-out retraining is unnecessary for the frozen SSL encoder, but any downstream-trained head must exclude pair glosses.
