# P112 — SignSeek (gloss-supervised articulator-masked contrastive pretraining for dictionary retrieval)

## Critical analysis

- Strengths: retrieval-first design; explicit frozen cross-corpus protocol; masked-articulator objectives with ablation; reports SignRep under the same retrieval protocol.
- INFERENCE (overlap risk): pretraining includes SemLex (ASL, isolated). Sem-Lex and ASL Citizen are both linked to the ASL-LEX lexicon (SignCLIP P110 Table 5 notes a Sem-Lex test subset "of 2,731 classes that are aligned with ASL Citizen/ASL-LEX"), so gloss-level label overlap between pretraining and ASL-Citizen evaluation is likely, even if videos/signers differ. The "unseen" claim refers to datasets, not vocabulary. Must audit before treating ASL-Citizen numbers as cross-vocabulary generalisation.
- INFERENCE: gloss supervision means SignSeek vs SignRep is labelled-vs-SSL — not a same-supervision comparison.
- Temporal: Conformer over full clip + attentive pooling (weighted sum, order-invariant readout); no order diagnostic.
- Nuisance: pose modality claimed "signer-invariant" (§1) — asserted.
- Pose noise: confidences fed as input channel; no explicit reliability objective.
- Limitations section: not found in extracted text (UNKNOWN).

## Liên hệ project

- Nearest competitor on the frozen ASL-Citizen dictionary protocol; it moves the bar from 49.95 (SignRep) to 57.66 R@1 with labels and pose. A new SSL RGB method claiming retrieval gains must state that SignSeek uses gloss supervision and pose.
- JEPA-style latent masked prediction (MAP) is already applied in sign (pose, labelled) → threatens novelty of "sign JEPA" framing; delta could be label-free + RGB.
- Cheap check: list ASL-Citizen gloss overlap with Sem-Lex vocabulary (metadata-only).
