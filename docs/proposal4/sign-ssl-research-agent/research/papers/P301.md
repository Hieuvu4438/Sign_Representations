## Mechanism

- Dataset paper; the "mechanism" is data collection: a web platform where Deaf/HoH participants watch a seed-signer video for each ASL-LEX sign and record themselves on their own webcam (§3.1), which yields many signers × full vocabulary × in-the-wild conditions, and labels that are tied to an ASL-LEX entry rather than to an English word.
- Authors expect signer-disjoint evaluation to match deployment ("it is unlikely that a user looking up a sign would be in the training set of a deployed model", §3.3).
- Novelty vs prior art: first crowdsourced ISLR dataset with consent/compensation; signer-disjoint official splits; IR metrics instead of top-1 only (§1, §3.3).
- Condition for validity: prompted recordings resemble real lookup queries (§3.3 "We expect our videos to be consistent with our chosen dictionary retrieval task").

## Critical analysis

- Strengths: signer-disjoint official splits; very large test set (11 signers × ~2,990 videos each; LOCAL_AUDIT) giving stable estimates; every gloss has an ASL-LEX code (enables linguistic diagnostics); IR metrics fit retrieval.
- Author-acknowledged limitations: fixed vocabulary; fluent Deaf signers only (novice gap expected); metrics may not match user preferences ("weighting relevance of signs with similar meanings or visual appearance"); 43–75% per-user accuracy spread; demographic disparities unexplored (§6).
- INFERENCE: the benchmark is closed-vocabulary — every test gloss has 9–24 training videos — so a frozen representation + trained linear head measures linear separability of seen classes, not open-set retrieval. Gloss-disjoint ("unseen vocabulary") evaluation must be built by the user (P311 does this).
- INFERENCE: DCG/MRR with a single relevant item are monotone transforms of rank; they add little beyond Rec@K except tail sensitivity. Rank ties are unspecified.
- INFERENCE: "N = 2729" in Appendix B vs 2,731 glosses — possibly two glosses dropped from model output space; unresolved. Note also LOCAL_AUDIT finding that 2,731 glosses map to only 2,723 distinct ASL-LEX codes (WHATFOR1/2/3 share C_02_054; RESEARCH1/2 share B_03_084; 6 glosses have code "NA").
- Confounds: participants filmed with the seed-signer prompt visible → possible imitation of seed-signer form (P310 reports a seed-signer-distance correlation for ST-GCN). Per-signer environment (room, camera) is constant within signer, so signer identity is confounded with background/lighting.
- Reproduction gaps: no seeds/variance; pose-extraction version for ST-GCN not pinned.

## Liên hệ project

- Primary benchmark: frozen-representation evaluation should report (a) the official signer-disjoint closed-vocabulary linear-probe Rec@1/5/10, DCG, MRR, and (b) a frozen-feature retrieval mode (test queries vs train gallery, cosine), following §5.3 / P314 SignSeek protocol (max-cosine per gloss) and P311 (centroid gallery), since §5.3 shows supervised-I3D frozen NN Rec@1 0.5803 and P314 reports SignRep frozen retrieval Rec@1 49.95 / DCG 71.21.
- Linguistic diagnostics: ASL-LEX join is clean via `ASL-LEX Code` column (see P302; LOCAL_AUDIT 2,725/2,731 glosses, 83,216/83,399 videos joinable).
- Signer diagnostics: each test signer covers ~all glosses → signer-ID probe and per-signer accuracy spread (cf. 43–75%) are cheap to compute on frozen features.
- Cheap experiment: frozen features → (1) linear probe official split; (2) NN retrieval vs train gallery, per-gloss max and centroid; (3) per-signer Rec@1 distribution; (4) signer-ID linear probe on test signers (leave-videos-out within signer).
- Claim ledger candidates: C-ASLC-SPLIT (signer-disjoint, closed vocabulary; LOCAL_AUDIT verified); C-ASLC-METRIC (Appendix B formulas).
