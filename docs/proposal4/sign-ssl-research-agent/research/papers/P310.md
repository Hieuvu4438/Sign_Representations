## Critical analysis

- INFERENCE: subgroup results rest on 11 test signers; with per-user accuracy spanning 43–75% (P301 §6) demographic effects are confounded with individual signers. Cluster bootstrap over signers is needed.
- Uses demographic metadata (supervision/sensitive attributes) — only for evaluation in this project, and only via the officially released data.
