## Critical analysis / Liên hệ project

- FACT-level support that pose sequences carry signer identity; therefore pose-teacher SSL targets (SignRep: 3D keypoints/joint angles) can transmit signer identity into representations.
- Project diagnostic: linear signer-ID probe on frozen features of ASL Citizen test signers (11 classes; each signer ~2,990 videos, P301 LOCAL_AUDIT), with gloss-disjoint train/test for the probe so it cannot use sign identity. Report alongside sign accuracy. Ethical note: probe uses provided participant IDs only; no face re-identification.
- Per project rule 10, signer-specific variation is not automatically nuisance; report leakage as a measurement, not as a defect by default.
