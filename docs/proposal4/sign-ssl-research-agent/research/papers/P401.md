## Mechanism

- Algorithm: frozen backbone → per-clip embeddings c_i. Some c_i are replaced by MSK, all get coordinate positional embeddings, plus a CLS token, then go through a transformer. Masked outputs are contrasted against the original clip embeddings, with other clips of the same video as hard negatives (§3.3, "the rest of the clips in the same video act as hard negatives"). CLS tokens of two disjoint clip sets from the same video are positives (SET).
- Gradient path: only the predictor and MLP heads. The backbone is frozen, so the per-clip features never change. Any gain must come from the aggregator and from refined per-clip outputs.
- Why it should work (authors): the clips are redundant, so predicting a masked clip from context forces inter-clip relations, and SET gives a global, crop-invariant summary.
- Temporal information enters only through the normalized (x, y, t) box coordinates (Eq. 5). The objective does not make the CLS depend on order. SET actually pushes the CLS to be invariant to which clips are sampled.
- Novelty claimed: training on sets of clips rather than pairs. Prediction is "continuous", over arbitrarily sampled space-time crops, not on a fixed grid (§2).

## Critical analysis

- Strengths: very cheap (stored features). Backbone-agnostic. Reports k-NN, a training-free probe, plus the necessary "same transformer, random init" control (Tables 3–7), which separates the SSL init from architecture capacity.
- Author-stated limitations / remarks: LVU videos partly unavailable, so not comparable (§4.1). Conclusion calls it "alarming" that contrastive (augmentation-invariant) features still support contrastive masked modelling, possibly via "benign memorization".
- INFERENCE: nothing in SCALE measures or requires temporal-order sensitivity. The time coordinate is an input feature, but SET (set-level invariance) and InfoNCE MCM can be solved without direction. No shuffle or reversal test is reported.
- INFERENCE: the k-NN gains are evaluated as instance-level classification on action datasets with train/test from the same distribution. There is no cross-subject or signer-independent split analogue.
- Confound: the hyper-parameter grid search split is unspecified (§4.1).
- Reproduction gaps: no code link in the text. k-NN uses k=20 on l2-normalized representations, "similar to DINO" (§4.1).

## Overlap with H1/H2

- H1 (label-free temporal encoder on frozen window embeddings → one retrieval vector). What SCALE already does:
  - frozen-backbone clip features as input (same input type as H1: per-window embeddings of a frozen video backbone);
  - masked feature prediction over the clip set (MCM), which is exactly H1's "masked feature prediction" variant;
  - a CLS-style single video vector;
  - evaluation with frozen k-NN, which is a retrieval-style probe.
- What SCALE does not do:
  - domain: action recognition only, no sign language;
  - window layout: clips are sparse random space-time crops of the whole video (5×3 test views), not a dense ordered sequence of windows over an active signing span, and there is no hand-activity weighting;
  - objective: no trajectory, straightening or direction objective. SET is an invariance objective;
  - evaluation regime: k-NN classification on UCF/HMDB, not open-vocabulary dictionary retrieval (R@k with a gallery) under a signer-independent split;
  - order: no time-reversal or order-sensitivity measurement.
- H2: no overlap. The backbone is never updated.
- Defensible delta for H1 versus SCALE: (a) sign domain with signer-independent dictionary retrieval, (b) an explicit order/direction requirement that SCALE's objectives do not impose, (c) a reversal-sensitivity measurement. The masked-feature-prediction-on-frozen-clips design is not novel by itself.
- Cheap separating experiment: train SCALE as-is (MCM+SET, coordinate PE) on SignRep window features and report ASL Citizen R@1 plus clip-vs-reversed cosine. If SCALE already matches H1's R@1 and drops reversal cosine, H1 adds nothing over SCALE.
- Follow-ups: LV-MAE 2504.03501 (masked-embedding AE on frozen segment features, long video). TCA (P206).
