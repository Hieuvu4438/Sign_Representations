## Mechanism

- Masked hand-pose token reconstruction with MANO decoder imposing kinematic plausibility; gradient flows through MANO (fully differentiable).
- Teacher noise: "Since hand pose detection results J_2D serve as the pseudo label, we ignore the joints with the prediction confidence lower than ε and utilize the remaining joints weighted by the confidence" (§3.2); ε = 0.5 (§4.2).
- Masking strategies partly mimic detection failures (joint zero-masking/random spatial disturbance; frame masking).

## Critical analysis

- Strengths: earliest sign-specific masked pose pretraining; explicit confidence-thresholded + confidence-weighted reconstruction — direct prior art for reliability-aware pose targets.
- INFERENCE: in-domain pretraining on benchmark training splits; no frozen eval by authors; 32-frame sampling loses fine timing.
- Temporal: masked frame modelling uses temporal context within 32 frames; attention-weighted temporal pooling at readout (order-invariant sum).
- Nuisance: hand pose input; no signer analysis.
- No ASL Citizen evaluation (dataset post-dates paper).

## Liên hệ project

- H-seed-B: confidence threshold + confidence weighting of pose targets has existed since 2021 (SignBERT §3.2); SignRep already uses confidence filtering (SIGNREP_AUDIT §5.1). Any reliability contribution must beat both.
