## Critical analysis

- Strong relevance: a gloss-disjoint retrieval protocol on ASL Citizen with frozen embeddings, plus evidence that gallery construction (all-instances vs centroid; #examples) changes Rec@1 by up to ~44 points.
- INFERENCE: comparisons of frozen representations must fix gallery construction (max-cosine per gloss as in P314, mean-of-instances, or centroid) — otherwise "representation" deltas can be post-processing deltas (project rule 20-experiments).
- Only ST-GCN tested; I3D/SSL encoders not evaluated (authors list as future work).

## Liên hệ project

- Adopt a gloss-disjoint "unseen vocabulary" retrieval track for frozen SSL encoders: queries from ASL Citizen test signers, gallery from train signers, glosses never used by any downstream head. Report both max-cosine and centroid galleries and K-shot gallery sizes (1, 5, 15).
