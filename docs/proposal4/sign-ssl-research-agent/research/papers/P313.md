## Critical analysis

- Not an isolated-sign benchmark; relevant as evidence that multi-stream SSL features can under-use face/non-manual channels.
- INFERENCE: for isolated-sign frozen representations, an analogous diagnostic is stream ablation at inference (mask face / non-dominant hand / body) on ASL Citizen glosses whose ASL-LEX coding or NMFs-CSL labels depend on that channel.

## Liên hệ project

- Supports a "cue ablation" diagnostic and a non-manual check (NMFs-CSL P315) for any pose-teacher-based SSL whose targets are hand/body only (SignRep targets: 61 3D keypoints, hands + body, no face — per anchor HTML summary).
