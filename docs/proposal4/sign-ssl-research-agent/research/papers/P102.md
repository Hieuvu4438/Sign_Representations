## Mechanism

- Moves DINO/iBOT from spatial crops to temporal crops of tracked articulator streams; teacher sees long (64–96 frame) windows, student sees short (10–32) windows → student must predict long-context prototype from short context (§3.2). Gradient only into temporal transformers + heads.
- Gram anchoring constrains intra-clip frame-to-frame similarity structure (Stage 2) — i.e., an explicit objective on temporal structure inside a ~64–96-frame clip.
- Novel vs SHuBERT (authors, §F discussion): continuous student/teacher distillation vs discrete cluster IDs; frozen DINOv3 vs fine-tuned DINOv2.
- Condition: frozen web-image DINOv3 must already encode handshape/face detail; tracker must be reliable.

## Critical analysis

- Strengths: explicit temporal-structure objective (long-vs-short temporal crops, Gram anchoring) with ablations showing both matter; three adaptation regimes reported including frozen + linear; seeds reported.
- Author-stated limitations (§5): tracker dropouts corrupt streams (validity mask only removes worst cases); frozen DINOv3 not trained on signing; no body-pose stream; ASL only; non-trivial preprocessing cost.
- INFERENCE: ISLR readout is "stream-fused, mask-aware time-average + BatchNorm + Linear" (App. E) — order-invariant pooling; the clip-level ISLR does not test order sensitivity. Global temporal crops are 64–96 frames, so temporal structure is modelled within that span, but no shuffle/reversal diagnostic is reported.
- INFERENCE: Table 4 mixes regimes (H2S BLEU from live-FT row, ASLC from full-FT row); the ablation is not frozen.
- Nuisance: crops discard background; no signer-shift or appearance analysis beyond qualitative clusters (App. B "recur across many backgrounds and skin tones" — qualitative).
- Detector noise: interpolation of gaps ≤ small K frames, per-frame validity mask excluded from SSL loss (App. E) — binary masking, not confidence weighting.
- Confounds: very recent unreviewed preprint; claims of public release unverified; baselines copied as published.
- Data-overlap evidence: the MS-ASL/YouTube-ASL test overlap statement (§4.3) implies any encoder pretrained on YouTube-ASL/YouTube-SL-25 (incl. SignRep) needs an overlap audit before reporting MS-ASL. Note: a string search of SHuBERT v3 HTML and SignRep v1 HTML finds no mention of MS-ASL, so the "as in SHuBERT" attribution is not traceable in SHuBERT v3 (UNKNOWN whether stated elsewhere).
- No dictionary retrieval / kNN evaluation (verified: Table 2 has only trained heads).

## Liên hệ project

- Strongest new prior art for H-seed-A (temporal structure objectives): long-context teacher + Gram anchoring already explored for cropped streams. Delta for this project would need RGB full-frame encoder (SignRep-style), pose-prior targets, and frozen retrieval eval.
- H-seed-B: binary validity mask from detector is the nearest baseline for reliability handling; soft weighting must beat it.
