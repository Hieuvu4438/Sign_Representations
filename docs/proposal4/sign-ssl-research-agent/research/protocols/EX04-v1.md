## Data / supervision

- Training: ASL Citizen **train** clips, cached frozen SignRep window `features` (stride 2) + activity outputs; no gloss labels, no signer IDs. Active span = windows with γ ≥ 0.5 (as in readout diagnostics); sequences capped at 48 windows (uniform subsampling if longer).
- Held-out for selection/monitoring: 5% of train clips (random, seed 0) — distillation loss only (no labels).
- Evaluation: official gallery protocol (train gallery → val queries, class-max cosine), R@1 primary; MRR/DCG/R@5 secondary; paired signer-cluster bootstrap vs baselines on the same queries.

## Arms (same architecture, steps, batch, optimizer, seed)

| ID | Training target | Purpose |
| --- | --- | --- |
| H4 | listwise KL to chamfer similarities over each anchor's 64 wmean-nearest train clips + in-batch | main |
| CM | same, teacher = wmean cosine similarities | capacity/aggregator control (same distillation, uninformative teacher) |
| CI | instance discrimination: two random temporal crops (≥ 60% of span) of the same clip are positives, InfoNCE over batch | generic label-free SSL control |
| floors/ceilings (no training) | wmean (paper readout) 0.5916, bins2 0.6491, chamfer 0.6840 (C002) | reference |

Architecture: per-window input = Linear(768→512)(window) + Linear(1→512)(γ) + sinusoidal embedding of normalised position in span; 2-layer Transformer (d 512, 8 heads, FFN 2048, dropout 0.1, pre-norm, key-padding mask); attention pooling with 4 learned queries → concat (2048) → Linear → 1024, L2-normalised. Training: AdamW lr 3e-4, wd 0.05, 3000 steps, batch 128 anchors, cosine schedule, warmup 200; τ_teacher = τ_student = 0.03 (fixed a priori). Checkpoint = last step.

## Decision rules (fixed now)

- PASS (→ generality checks + confirmatory protocol): H4 − bins2 ≥ +1.0 R@1 (CI > 0) **and** H4 − CM ≥ +2.0 **and** H4 − CI ≥ +2.0.
- PARTIAL: H4 > wmean by ≥ +3.0 but fails one of the above → report; at most one declared revision.
- REFUTE: H4 − wmean < +1.0.
- Cost report: index size and query time vs chamfer.
