## Gate rule (spec §10.2, unchanged)

Per edge a→b (12) × horizon δ ∈ {2,4,8} (geometry block): gate = 1 iff ≥ 10 groups and ≥ 1000 examples, relative MSE gain (G0→G1) ≥ 5%, 95% signer-cluster bootstrap CI of Δ = MSE(G0) − MSE(G1) > 0, G1 better than Gsh with CI > 0, increment RMS ≥ 0.05.

## Decision rules for the CIP direction (fixed now)

- **NO_VALID_EDGES** (0/36 gates) → per spec §10.5 the CIP target is effectively zero in this setting; CIP student pilot NOT run; report negative premise result.
- **Valid edges exist** → inspect which (hand↔hand symmetry is expected and partly trivial); if gates pass only on edges whose increment is explainable by shared global motion (e.g. BODY→hands via torso sway), treat as weak. Proceed to a student pilot (C1 vs B4 vs B6, SignRep warm-start continuation track, matched budget) only if ≥ 1 hand-target edge passes at δ ≥ 4.
- Also reported: persistence baseline, absolute MSEs, all 36 edges (not only passing ones).
