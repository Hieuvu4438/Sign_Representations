# EX04-v2 — The single declared revision of H004 (written after EX04-v1 results)

## Status

LOCKED 2026-10-06 before v2 training. **Exploratory with respect to EX04-v1** (the revision was chosen after seeing v1 results); any v2 gain needs a fresh confirmatory protocol (new seeds + second dataset) before a claim.

## v1 outcome (REFUTE by v1 rules)

H4 0.6011 R@1 (H4 − paper wmean +0.95 [−3.76,+4.41]; H4 − bins2 −4.79 [−9.19,−1.56], 0/6 signers); CM 0.5576 (< wmean 0.5916); CI 0.3018.

## Diagnosis (one cause)

The control CM — same aggregator distilling plain wmean cosine — is **below** wmean itself, so a randomly-initialised transformer + attention-pool cannot even reproduce the teacher geometry in 3000 steps. The failure is the student parameterisation, not (yet) the chamfer target.

## Single revision

Student = **soft temporal segment pooling initialised at bins2**: K = 2 segments; per-window soft assignment w_k(t) = softmax_k(β·(c_k − |τ_t − μ_k|) + MLP([x_t; τ_t]) ), with μ = (0.25, 0.75), MLP last layer zero-initialised (so at init w ≈ hard 2-bin partition by position τ); segment vector s_k = L2N(Σ_t w_k(t)·γ_t·x_t); output = L2N(concat(s_1, s_2)). Trainable: μ, β, MLP (768+1 → 128 → 2). Same data, teacher (chamfer, H4) and control teacher (wmean, CM), same steps/batch/τ/lr.
