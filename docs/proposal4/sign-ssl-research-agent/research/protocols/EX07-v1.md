# EX07-v1 — Confirmatory on a fresh holdout (MS-ASL test): readout replication + label-free whitening

## Status

LOCKED 2026-10-06 ~12:40 +07, before any MS-ASL feature was extracted. MS-ASL has never been used by this project.

## Hypotheses

- **H-R (replication of C012 on a third dataset):** R1 (bins2) > R0 (paper readout).
- **H-W (C004, label-free nuisance reduction):** PCA-whitening fitted on the *unlabelled train gallery* improves the ordered single-vector readout: R1W > R1. Development evidence (ASL Citizen val, exploratory, k chosen there): R1 0.6491 → R1W 0.6748 (+2.57 [+1.33,+3.82]); plateau for k ∈ {512, 640, 768}; window-level whitening + chamfer 0.703 vs 0.675 (3,000-query subset).

## Data

MS-ASL local cut clips (`/home/dongvk/datasets/MS-ASL/cut_processed_video`, split/class from `metadata_msasl_like_wsasl.json`): gallery = train (12,711 clips, 1,000 classes), queries = test (2,847 clips, 944 classes). Labels used only for gallery class identity and scoring. Contamination: ≈ 38% of MS-ASL test samples come from YouTube-ASL videos (P307), which may be in SignRep's unlabelled pretraining data → absolute numbers are not clean; relative comparisons on identical embeddings are the object of this protocol. Signer IDs are not mapped for the cut clips → bootstrap clusters = classes.

## Readouts (all fixed now)

- R0: SignRep paper readout (activity-weighted mean, whole clip).
- R1: bins2 over active span (γ ≥ 0.5), as in EX05.
- R1W: R1 with per-half PCA-whitening: centre on the train-gallery mean, project on the top k = 512 principal directions, divide by (σ_i + 0.01·σ_1), L2-normalise each half, concatenate, L2-normalise. Fitted on train-gallery clip vectors only.
- R2: chamfer@20 (EX05 definition). R2W: same, with window-level whitening (k = 512, same shrinkage) fitted on ≤ 300,000 randomly sampled train-gallery active-span windows (seed 0), windows L2-normalised after whitening; R2W's top-20 classes come from the whitened-window weighted mean.

## Statistics and decision

Paired bootstrap over classes (10,000), Holm over the two primaries (R1 − R0, R1W − R1).
- H-R SUPPORTED if R1 − R0 > 0 with Holm-adjusted CI > 0.
- H-W SUPPORTED if R1W − R1 ≥ +1.0 R@1 with Holm-adjusted CI > 0; REFUTED if ≤ 0; else INCONCLUSIVE.
- Secondary (descriptive): R2 − R0, R2W − R2, R1W − R0.
