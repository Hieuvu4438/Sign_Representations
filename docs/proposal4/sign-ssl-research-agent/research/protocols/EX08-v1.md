# EX08-v1 — CIP-Sign premise on continuous signing (How2Sign)

## Status

LOCKED 2026-10-06 before any How2Sign state/forecaster was computed.

## Why

EX03 refuted the CIP premise (0/36 gates) on isolated ASL Citizen signs; a key scope limitation was "isolated signs". proposal5's canonical source is continuous signing (YouTube-SL-25, not available locally). How2Sign train (continuous ASL, local COCO-WholeBody 2-D keypoints in the same format as ASL Citizen) removes that limitation at low cost; the teacher limitation (2-D, no appearance) remains.

## Setting (identical to EX03-v1 except data and grouping)

- Data: random 8,000 How2Sign **train** sentence clips (seed 2026; sentence text/gloss never read); states by `p4/cip_states.py` (same definitions, thresholds re-calibrated on this data).
- Groups: YouTube `video_id` (from file name prefix) — signer IDs not read. Calibration = 5% of groups; the rest in 5 group folds.
- Forecasters G0/G1/Gsh, budgets, common-support evaluation, gate rule (≥ 10 groups, ≥ 1000 examples, rel. gain ≥ 5%, Δ CI > 0, G1 < Gsh CI > 0, increment RMS ≥ 0.05): unchanged from EX03-v1 / proposal5 §10.2.

## Decision

- NO_VALID_EDGES → CIP premise refuted for 2-D geometry on continuous signing too; H003 remains closed.
- ≥ 1 hand-target edge passing at δ ≥ 4 → premise holds in continuous signing; report which edges; a student pilot would then need a continuous-signing RGB pipeline (resource request), not run automatically.
