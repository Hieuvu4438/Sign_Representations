# EX09-v1 — CIP-Sign premise with a proposal5-style teacher (appearance + MediaPipe 3-D hands), continuous signing

## Status

LOCKED 2026-10-06, after a 3-clip smoke test of the extractor, before any forecaster was trained on these states.

## Why

EX03 (isolated) and EX08 (continuous) refuted the CIP premise with 2-D COCO-WholeBody geometry only. The last untested element of proposal5's teacher is the appearance block (DINO crops) and MediaPipe hand landmarks with relative z. This run closes that gap as far as local assets allow.

## Teacher states (deviations from proposal5 §6 declared)

- Source: first 1,200 clips of the EX08 How2Sign sample (seed 2026); raw video → SHuBERT author preprocessing (YOLO signer crop, MediaPipe pose/face/hand landmarkers, author hand selection by pose wrist) via `shubert/extract_cip_teacher.py`.
- Appearance (per part LH, RH, FACE): DINOv2 ViT-S/14-reg **fine-tuned on hand/face crops by the SHuBERT authors** (proposal5 specifies generic DINOv3-S/16 with DINOv2-small fallback; the author fine-tuned weights are the locally available DINO teacher). Projected to 128-d by PCA fitted on the calibration groups only; valid only on frames where that part is genuinely observed (not carried-forward crops). BODY appearance invalid (as in proposal5).
- Geometry: LH/RH = 20 MediaPipe hand joints relative to wrist / wrist→MCP9 distance with x,y and detector-relative z (60) + wrist relative to shoulder midpoint / shoulder width (2) + log(sH/sT) (1); FACE geometry absent (no blendshapes stored) → FACE = appearance only; BODY = MediaPipe pose points [0,7,8,11,12,23,24] relative to torso / shoulder width (14) + shoulder direction (2) + log scale (1).
- State = [appearance 128 | geometry ≤ 96] (proposal5 layout D = 224), z-scored with calibration-group statistics.
- Groups = YouTube video id; calibration = 5% of groups; 5 group folds; forecasters/gates/common support as EX03/EX08 and proposal5 §9–§10; block weighting: per-block MSE averaged over valid blocks (appearance, geometry), as §11.1.

## Decision

Gate rule unchanged. NO_VALID_EDGES → CIP premise refuted for this teacher as well (H003 closed for all locally testable teachers). Otherwise report passing edges/blocks and whether hand-target edges pass; a student pilot would require new resources (RGB continuous-signing training pipeline) and a new protocol.
