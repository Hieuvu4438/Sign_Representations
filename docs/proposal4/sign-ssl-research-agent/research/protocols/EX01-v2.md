## Questions

**Q-G1 (baseline).** With the paper protocol (16 consecutive native frames, stride 2, z^avg = `features`, activity-weighted average with γ = clip(max(P_LH,P_RH),0,1), cosine, train gallery, 1-NN / class-max ranking), what are DCG/MRR/R@1/R@5 on ASL Citizen **val**? REPORTED_RESULT to compare: SignRep v1 **Table 4** (frozen, ASL Citizen **test**): weighted DCG 71.21 / R@1 49.95 / R@5 80.09; avg DCG 61.40 / R@1 37.47 / R@5 68.77. (Table 3, 90.84/81.37, is fine-tuned recognition — not this setting.)
- Decision rule (val vs test differ in signers, so only coarse agreement is expected): if weighted val R@1 within ±0.08 of 0.4995 and avg within ±0.08 of 0.3747, and weighted > avg → protocol matched (EVAL_REPRODUCED-on-val, not test). Otherwise PARTIAL: diagnose preprocessing/pooling before using as baseline. Internal comparisons stay valid either way.
- Variants (same windows): features+activity (paper), features+mean, latent+mean, latent+activity, features+mean at stride 16 (windows subsampled).

**Q-T (temporal information).** How much of frozen retrieval depends on within-window temporal order and motion? Gallery stays unperturbed; only the 2000 val queries are perturbed:
- P0 none; P1 `reverse` (whole clip reversed in time); P2 `shuffle` (fixed random permutation of the 16 frames inside every window); P3 `static_mid` (every window = its 9th frame repeated 16×, i.e. no motion inside windows, window positions unchanged).
- Metric: R@1 and MRR with features+activity and features+mean pooling, paired per query vs P0.

Predictions written before results (INFERENCE from SignRep's per-frame static prior targets + 16-frame windows):
- If the representation is dominated by static configuration (handshape/location/pose), P3 keeps a large fraction of P0 (> 70% of P0 R@1) and P1 is close to P0 (> 85%).
- If it encodes motion direction, P1 drops clearly (< 70% of P0 R@1) because reversed signs are mostly different/ungrammatical signs.
- Interpretation limits: P2/P3 are out-of-distribution inputs; a drop can come from distribution shift rather than loss of motion information. P1 is the cleanest test (in-distribution frames, only the arrow of time changes) but some signs are near time-symmetric. No linguistic claim follows from these numbers alone.
