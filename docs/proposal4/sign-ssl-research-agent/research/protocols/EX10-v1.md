# EX10-v1 — Second-encoder confirmation on test: SHuBERT readouts, ASL Citizen test (within-test leave-one-signer-out)

## Status

CANCELLED 2026-10-06 (~50 test clips extracted, no result computed, features deleted) — user instruction: SHuBERT is reference only, do not pursue it further.

## Design

- Encoder: SHuBERT residual stream, layer 12 (as EX06b; pre-declared), extractor `shubert/extract.py --hidden residual` (2 workers, user process limit).
- Data: ASL Citizen **test**, a fixed random 50% of clips (seed 20261006, stratified by nothing; list saved to `method/p4_signssl/configs/test_half.txt` before extraction). Protocol = leave-one-signer-out **within this test half** (gallery = the other 10 test signers' clips in the half; class-max cosine). Avoids extracting the 40k train split (~41 h with 2 workers). The ASL Citizen test split was already used once by this project (EX05) for SignRep readouts; SHuBERT has never been evaluated on it.
- Readouts (EX06 definitions): S1 mean over valid span (reference), S2 bins2, S3 chamfer@20. SignRep is evaluated under the identical within-test LOSO protocol on the same clips (R0 paper readout, R1 bins2, R2 chamfer) for comparability (features already extracted).
- Statistics: paired signer-cluster bootstrap (11 clusters, 10,000 resamples), Holm over SHuBERT S2 − S1 and S3 − S1.

## Decision

SUPPORTED_WITHIN_SCOPE for the second encoder if S2 − S1 > 0 with Holm-adjusted p < 0.05 and CI > 0; REFUTED if ≤ 0; otherwise INCONCLUSIVE.
