## Arms (identical init, data order, mask seeds, steps, batch, heads)

B0: final-stage masked JEPA (κ = 0). B1: mid + final masked + context (κ = 0.05). B4: B1 + local state (α = 0.5) + change (β = 0.1, lags of ≈ 80/160 ms) + coverage routing (A ≥ 0.25, ±2 tokens). C4a (only if B4 − B1 > 0): B4 with random gates matching the coverage-gate retention rate.
3000 steps, batch 8, 80% hidden mask units, EMA 0.996→0.9999, seed 17; last step evaluated.

## Evaluation (validation only)

Extract val windows (stride 4) with each online encoder (`features` = SignRep fc on the backbone mean, i.e. the published readout path), activity weights from the original model; leave-one-signer-out on ASL Citizen val; readouts R0 (SignRep) and R1 (two-segment). Reference: original SignRep R0 0.4950 / R1 0.5388 (stride 4).

## Decision rules

- Mechanism (proposal's claim): B4 − B1 ≥ +1.0 R@1 (R0 readout) with CI > 0 → continue to C4a and multi-seed; ≤ 0 → proposal refuted in this setting.
- Usefulness: best arm vs original SignRep (R0 and R1). The spec's pilot criterion is ≥ +2 points.
- Any arm below the original by > 2 points is reported as degrading the warm-started representation.
