# Implemented method

Each canonical 25 Hz frame supplies frozen L2-normalized original DINOv2 ViT-S/14 features for anatomical left/right crops and shoulder-centered, pixel-aspect-correct 14-dimensional upper-body coordinates. Nearest decoded PTS within 40 ms defines observations; missing features remain invalid and zero. Pose wrists associate hands; ambiguous assignments are dropped, raw MediaPipe category consistency is anchored to each pose track without assuming mirror status.

Student inputs replace valid SSL-masked hand/body content with learned masks and keep natural missing tokens distinct. The time-major LH,RH,BODY sequence enters a joint bidirectional Transformer. Clean qualities affect target weighting only. Hand decoders predict raw 384D features and minimize squared L2 sum per state, weighted and reduced within each hand then averaged over active hand streams. Body loss is quality-weighted valid-coordinate SmoothL1. In A4, normalized hand predictions also match clean LH(t)–RH(t+lag) cosine similarity using weighted SmoothL1(beta=.1), sparse lag-stratified edges with at least one masked endpoint. Nonzero-lag same-source-frame pairs are rejected; no circular wrapping. Maximum32 pairs/window; lag set {-8,-4,-2,-1,0,1,2,4,8}; relation coefficient ramps to .1 over100 successful updates.

Controls preserve teacher/cache/window/mask/init/optimizer/pooling: A1 disables relation contribution, A2 positive-lag same-hand edges, A3 zero-lag cross-hand, A6 same-lag cross-window shuffled clean relation targets. Shuffled buckets with only one window are excluded and logged. A5/A7 are optional and not implemented as measured experiments.

Training uses AdamW, microbatch8×accumulation4, weighted microbatch means, cosine schedule with100-step warmup, BF16 when supported, clipping1.0 and deterministic RNG plans. No EMA encoder, contrastive negatives, learned relation head, signer adversary, VICReg loss or learned pooling is used. Labels are only joined after frozen embedding export.
