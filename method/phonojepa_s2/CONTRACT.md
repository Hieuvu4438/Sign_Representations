# S2 implementation contract

Material Passport: S2 experiment implementation, proposal12 §7; adaptation, not a Path-JEPA reproduction. Same ASLC002 3,000 training videos, scratch encoder6×256/heads4 and predictor4×128, same optimizer/batch32/budgets and shared evaluation. Existing S1 files/jobs are immutable inputs.

1. Primary input is unchanged S1 eight-channel features. Context-only, motion, signature, raw-difference and motion-MAE controls use identical input/mask/architecture. Auxiliary targets never enter encoder inputs.
2. Motion: signed 2D changes and magnitudes at lags1/4/8, path length, mean step speed, radial shape-change rate. Physical derivatives divide by actual source-time delta after speed resampling. Raw frame-difference and single-lag controls have identical output/head capacity with inactive dimensions masked.
3. Path set covers D/N wrists, index tips, forearm and upper-arm relative vectors, index-to-wrist shape, wrist-to-head and wrist-to-wrist relations, and shoulder/elbow/wrist chain-bend residuals. All are selected 2D trajectories, not all finger pairs.
4. Intervals: 8/16/32 samples, half-window stride, complete intervals only. An interval requires **all** joint observations at **all** its contiguous samples. Hidden-input interval is never created by filling a gap with zero or joining separated observations.
5. Degree2 log-signature has d + d(d−1)/2 coefficients: plain2D=3, standard lead–lag4D=10, no scalar. Chen-based exact piecewise-linear degree2 calculation in torch; validate against independent tensor-algebra reference and known path geometry.
6. Signature loss keeps a start/end level branch; motion targets retain speed/rhythm information. Query metadata includes path, start, scale and physical duration. No global descriptor is broadcast into local visible input.
7. Raw interpolation support is exported as a forbidden-joint mask. Descriptor visibility requires contiguous student observations AND no forbidden dependency anywhere in its support. Target query selection requires a forbidden endpoint and a corresponding masked token query. Duplicate wrists/nose and anchor policy inherit reviewed S1 closure. Overlapping scales are checked separately.
8. Loss: λ_ctx L_ctx + λ_motion L_motion + λ_signature(L_logsignature + .25 L_start_end), with optional S1 body/relations auxiliaries kept as separately reported factors. Per-path/group balancing and robust training-only normalization; no validation fitting. Compare learned contextual targets, deterministic motion targets and motion-MAE.
9. Optional descriptor-input arm uses the same encoder backbone with a descriptor tokenizer and path/time/scale metadata. Motion-only and signature variants have equal token slots and padded descriptor dimension for capacity matching. Student descriptor tokens containing forbidden sources are absent as attention keys; teacher may use the clean full path. Auxiliary heads are discarded for inference.
10. Pose-only readout retains static D/N/face/torso pooling plus ordered temporal summaries; gallery-only PCA maps to primary768 dimensions. Same unchanged evaluator and smoke/mixed-checkpoint guards as S1.
11. Review stages: data/math → masking/targets/model → training/resume → extraction/protocol. Verify with mathematical oracles, metamorphic/leakage tests, real data and CPU/CUDA smoke. Full research training is outside this code/setup request.
