# S27 — Confidence sequences without replacement

Ian Waudby-Smith, Aaditya Ramdas; NeurIPS2020.
[Proceedings](https://papers.nips.cc/paper/2020/hash/e96c7de8f6390b1e6c71556e4e0a4959-Abstract.html),

full construction/proofs/software not reviewed. Browser PDF, no local page anchors.

Finite population values are fixed; random order without replacement supplies
the probability model. Time-uniform coverage permits data-dependent stopping,
where repeated fixed-time intervals generally do not. Continuous observations
need known bounds. This motivates a possible probabilistic H004 variant, but no
confidence sequence is implemented, validated or measured here. A maximum fitted
on seen windows is not automatically a population bound. Coordinate/frame
dependence cannot be dismissed as IID; simultaneous gallery/class comparisons
would need explicit risk allocation. Core sequential statistics are existing work.
