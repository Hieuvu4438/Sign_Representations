# S39 — YouTube-SL-25 provenance and release identifiers

Garrett Tanzer, Biao Zhang. [Primary arXiv2407.11144v1](https://arxiv.org/html/2407.11144v1),
2024-07-15, access2026-10-04. Venue unverified. Selected introduction,§2/2.1/initial2.2,
not full model/results/code review. [Author release](https://github.com/google-research/google-research/tree/master/youtube_sl_25)
links a public GCS source-ID corpus; console URL redirects to login in web tool.
Read-only bounded public object-metadata API alternative registered separately.

The multilingual corpus contains YouTube-ASL as a subset and releases YouTube
video identifiers. These identify collection sources, not the exact filtered
subset used to train a particular SignRep checkpoint. Continuous captions and
language labels do not supply a complete isolated-gloss class-membership ledger.
Local YouTube-ASL ID list alone therefore cannot certify full YouTube-SL-25 or
SignRep training coverage. ASL Citizen numeric recording filenames cannot be
compared as equivalent YouTube IDs without source mapping. No video/caption
content downloaded; no disjointness from failed/mismatched ID intersections.
