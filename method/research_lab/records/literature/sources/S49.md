# S49 — Conformal Risk Control

Anastasios N. Angelopoulos; Stephen Bates; Adam Fisch; Lihua Lei; Tal Schuster.
[arXiv2208.02814v4](https://arxiv.org/html/2208.02814v4),2025-06-13;
first submitted2022-08-04; access2026-10-05. Venue unverified in this audit.
Selected §1.1 and §2.1 Theorem1/proof; extensions and remaining proofs unread.
Official code linked from abstract, not inspected/pinned. No implementation run.

The main construction bounds expected bounded monotone loss using exchangeable
calibration/test loss functions and a finite-sample correction. It is not a
blanket per-signer or conditional-on-acceptance guarantee. Applying it requires
specifying the actual loss and calibration unit, not merely a confidence score.
The paper includes distribution-shift extensions; their assumptions were not
audited here, so no assertion that all shift control is impossible.

H007 inference: calibration on dictionary-present signs alone cannot, by itself,
bound acceptance of missing-class signs from an unrestricted different
distribution. This is our task-specific logical observation, not the paper's
reported sign-language result. It rules out an unjustified guarantee, not an
empirical calibration experiment. Grouped clips do not supply i.i.d. signer data.
Grade: selected primary theoretical text; not a sign task/reproduction. COI and
venue assessment unknown; follow-up loss/unit/assumption mapping before use.
