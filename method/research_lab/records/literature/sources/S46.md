# S46 — Automatic Hand Sign Recognition: Identify Unusuality through Latent Cognizance

Pisit Nakjai; Tatpong Katanyukul. ANNPR2018,255–267,verified
[publisher contents](https://link.springer.com/book/10.1007/978-3-319-99978-4?page=2).
[Author arXiv2110.15542v1 PDF](https://arxiv.org/pdf/2110.15542),uploaded2021-10-29;
access2026-10-05. Selected §§3–4/Tables3–4, not full-paper/code review.

The study uses cropped RGB images, supervised VGG-16 Thai fingerspelling
classification and score thresholding to detect invalid postures. §4 describes
25 valid postures/12 signers, signer-separated valid-image folds and a separate
invalid-posture collection from one signer. Tested scores include maximum
pre-softmax output, top-two difference and aggregate cognizance functions.
Reported performance is not reproduced. Its AUC/ROC labels use unusual
terminology (§4); do not assume scorer equivalence or import those numbers.

This is rejection prior art, but invalid fingerspelling posture detection differs
from rejecting a valid isolated lexical sign absent from a changing dictionary.
Code/checkpoint, invalid-signer overlap, exact score calibration and provenance
unknown. No video temporal-context claim.
The related arXiv2110.15548 is a separate softmax-interpretation article;
its intro points backward here, not an interchangeable task evaluation.
H007 follow-up: strong score controls and genuine missing-class label definition.
Grade: selected primary computational evidence, no local reproduction;
COI/venue-process audit unknown.
