# S48 — A Baseline Study and Benchmark for Few-Shot Open-Set Action Recognition with Feature Residual Discrimination

Stefano Berti; Giulia Pasquale; Lorenzo Natale.
[arXiv2603.04125v2](https://arxiv.org/html/2603.04125v2),2026-06-08;
access2026-10-05. Selected §§3,4.2,5.1–5.2; first inspected v1, then v2.
Venue unverified. [Author project](https://hsp-iit.github.io/fsosar/) links
[official repository](https://github.com/HSP-IIT/fsosar); commit/code uninspected.

Tasks mix queries whose class is present/absent from few-shot support. Metrics
include OSCR, which couples correct known-class acceptance with unknown false
acceptance; unknown-only AUROC does not measure classification accuracy.
FR-Disc learns rejection from the query-minus-nearest-support feature residual,
with correctly classified known positives and unknown negatives. Comparators
include maximum-logit/softmax scores, entropic training and a garbage prototype.
This is supervised episodic adaptation of RGB action representations, not our
frozen SignRep protocol. Training splits/supplement/code and results not reproduced.

H007: residual rejection networks and a video few-shot open-set benchmark already
exist. Adding that module to signs is not intrinsically a new method. OSCR is a
scorer lead requiring exact tie/endpoint/parity audit.
Grade: selected primary computational evidence; COI/peer-review process unknown.
