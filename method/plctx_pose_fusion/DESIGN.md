# PLctx + pose body/relations: gated residual fusion

## Material Passport

Date2026-10-16; scope:user-authorized full ASL-Citizen training setup. Design adaptation of local PLctx and Pose-JEPA, not reuse of deleted Pose-JEPA weights. Existing methods/jobs/datasets are read-only. No claim of accuracy gain. Implementer review and execution evidence are recorded separately.

1. Keep the complete seven-channel PLctx full160 EMA encoder frozen, including hand and face context, initialized from SHA-pinned existing weights. Do not isolate a fictitious pure-handshape subspace or overwrite learned features.
2. Train a separate body/arm graph branch from scratch: frame-local spatial message passing with per-joint LayerNorm, ordered-node aggregation, temporal Transformer, and explicit relation tokens. Body frame uses allowed shoulders; hips/head/wrist geometry remains in body units. Body streams: core torso, each shoulder-elbow-wrist chain, selected hand/body/head relations. This adapts Pose-JEPA's spatial frontend; graph layout and inputs are explicitly defined and differ from the old four-part checkpoint.
3. Fuse each PL token with graph context through cross-attention and a bounded, initially small gate. Preserve all original PL groups; final embedding remains D/N/face concatenation768. Gate0 must reproduce frozen PL exactly under identical preprocessing/pooling. Provide graph-only and gate0 diagnostic readouts; no test-set gate selection.
4. Train masked contextual EMA prediction plus hidden-endpoint body/relations geometry, and visible PL retention loss. Teacher geometry uses student augmentation/reference; no auxiliary target enters student input. Warm up geometry/graph learning before opening gates to their configured maximum. No gloss labels in SSL losses.
5. Use reviewed raw masks on eight channels (PL7 + masked torso), duplicate wrist/nose closure, source interpolation dependency propagation and explicit forbidden support. Spatial messages never read forbidden nodes; a graph token is a valid context key only if every declared raw dependency is allowed. Missing joints remain absent; no derivatives cross missing samples. Shared shoulders and whole-clip dominance are declared side information.
6. Full official train40154; batch32;160 epochs=200640 optimizer steps. This is additional training after existing PLctx160 pretraining, not scratch-compute-matched with older runs. Pose branch starts fresh. Save/model-select against fixed full official validation10304, never official test32941 during training.
7. Validation at step0 (gate0 PL baseline), graph-warmup boundary2000, every5000 updates and final. Report raw frozen dictionary DCG/Rec1/5 plus gate0 on same windows. Select best fusion by raw validation Rec1, with deterministic ties keeping earlier checkpoint. Retain last/previous/best and sparse stage checkpoints, not unlimited snapshots.
8. Atomic full checkpoint contains both branches, EMA, predictor/heads, optimizer, centers/stats, RNG and consumed-step data cursor. Restore interrupted validation before training advances. SIGTERM/INT saves update boundary. Fallback only for unreadable/corrupt last; source/config/data mismatch must fail closed. Resume must be tested against uninterrupted state.
9. A persistent systemd user service with Linger survives logout/reboot, uses immutable job source/config snapshots and single-instance lock. Queue on free VRAM threshold, not unrelated process presence; join while others run if enough memory.
